# Ihre Website selbst bearbeiten — Kurzanleitung

Ihre Website hat einen geschützten Verwaltungsbereich, mit dem Sie Texte und Bilder jederzeit selbst ändern können. Sie brauchen dafür keine technischen Kenntnisse.

## Anmelden

1. Öffnen Sie im Browser: **https://www.alpenglanz-hausservice.at/admin/**
2. Geben Sie Ihr Passwort ein und klicken Sie auf „Anmelden“.

Beim allerersten Aufruf legen Sie Ihr Passwort selbst fest (mindestens 10 Zeichen, am besten ein ganzer Satz). Bewahren Sie es gut auf.

## Texte ändern

1. Wählen Sie in der Übersicht die gewünschte Seite (z. B. „Startseite“) und klicken Sie auf **Bearbeiten**.
2. Ändern Sie den gewünschten Text direkt im Feld.
3. Klicken Sie unten auf **Änderungen speichern**. Fertig — die Änderung ist sofort online.

Das Design der Website (Farben, Schriften, Anordnung) bleibt dabei automatisch erhalten. Sie können nichts kaputt machen.

**Wichtig bei zwei Sprachen:** Ihre Website gibt es auf Deutsch und Englisch. Wenn Sie einen Text ändern, denken Sie bitte auch an die englische Seite (z. B. „Startseite (Englisch)“).

## Bilder austauschen

1. Öffnen Sie die Seite mit dem Bild über **Bearbeiten**.
2. Wählen Sie unter „Bilder“ eine neue Datei aus (JPG, PNG oder WebP). Große Fotos werden schon beim Auswählen automatisch verkleinert, damit Ihre Website schnell bleibt.
3. Klicken Sie auf **Änderungen speichern**.

## Etwas schiefgelaufen? Kein Problem.

Vor jedem Speichern wird automatisch eine Sicherung angelegt. Klicken Sie bei der jeweiligen Seite auf **Verlauf** und stellen Sie eine frühere Version mit einem Klick wieder her.

## Google-Vorschau

Ganz unten beim Bearbeiten finden Sie „Google-Vorschau“. Diese Texte erscheinen in Google-Suchergebnissen. Ändern Sie sie nur, wenn Sie wissen, was Sie tun — im Zweifel einfach so lassen.
